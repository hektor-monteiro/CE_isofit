Welcome to CE_IsoFit's documentation!
=====================================

CE_IsoFit is a pipeline designed for fitting isochrones to open cluster data from the Gaia DR3 release. It employs a Cross-Entropy (CE) optimization method to estimate essential cluster parameters such as Age, Distance, Metallicity ([Fe/H]), and Extinction (Av).
